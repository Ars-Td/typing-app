# MVP Acceptance Checklist

仕様: [docs/specs/mvp.md](../specs/mvp.md)

## 画面とフロー

- [x] ホームでアプリ名「返信打」、難易度 3 択（呼称つき）、時間 1/2/3 分（既定 2 分）、CTA「シフト開始」、分析リンクがある
- [x] 自己ベスト年収があるときホームに小さく表示される。ないときは出さない
- [x] プレイは Slack 風（サイドバー・チャンネルヘッダー・メッセージ・下部コンポーザー）
- [x] HUD に残り時間と累計年収がある
- [x] お手本日本語は全文見え、確定は緑、現在位置はピンク、未入力はグレー。ローマ字補助行がある
- [x] 時間切れで結果へ。未送信の途中入力は報酬に入らない
- [x] 結果に年収ヒーロー、WPM/CPM、正確性、ミス数、最大連続、難易度と時間の回顧がある
- [x] 結果から再挑戦（同設定）・ホーム・分析へ行ける
- [x] 分析は苦手キー / 指 / 動きの 3 セクション。データなしは空状態
- [x] プレイ中断はスコアを保存せずホームに戻る

## ルール

- [x] 同一プレイ内はプールを使い切るまで重複しない。使い切ったらループする
- [x] し/si・shi、つ/tu・tsu、ち/ti・chi、ふ/hu・fu、ん/n・nn など一般的なローマ字揺れを受け付ける
- [x] 英数字・記号・Markdown・@mention・#番号は表示と同じキー
- [x] 改行問題は未完了 Enter が改行、完了後 Enter または送信ボタンで送信
- [x] Backspace で未確定 / 誤入力を消せる。ミス回数は消えない
- [x] キー入力イベントをプレイ中に API へ送っていない

## スコアと分析

- [x] 1 件報酬が `round(基本額 × 速度係数 × 正確性係数)` で、速度 0.7〜1.5、正確性の下限 0.3
- [x] CPM/WPM は正しい打鍵のみ・制限時間ベース
- [x] 苦手キーの母数 20 未満は参考扱い
- [x] 指は JIS ホームポジション。Shift 記号はその文字キーの指
- [x] バイグラムのミスは 2 打目のミス

## データ / API

- [x] 問題とプレイ結果が D1 にある。migration でスキーマ変更する
- [x] ローカル D1 と本番 D1 が分かれている
- [x] 各難易度 12〜15 問。世界観と自然な業務チャットになっている
- [x] 匿名 ID のみ。個人情報カラムがない
- [x] `GET /api/problems`、`POST /api/plays`（終了時）、`GET /api/stats`

## 開発と品質

- [x] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [x] `just check` が lint・typecheck・test・build を通す
- [x] ローマ字・報酬・集計のテストがある

## デプロイ

- [x] Wrangler で Workers にデプロイでき、本番 D1 に問題データが入っている
- [x] デプロイ先 URL でホームからプレイまで動く
